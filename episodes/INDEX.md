| 004 | 2026-06-20 | [Holding Pattern](../episodes/004-verification-bottleneck/post.md) | The verification bottleneck, told as the honest upside story: once agents make code generation free, generation stops being the constraint and the bottleneck relocates to verification (proving the code is right). The twist: verification is far more automatable than people assume, so the constraint doesn't stop there — it climbs upstream every time you mechanize a stage, until it reaches the one node with no machine oracle, deciding what "correct" means. So the engineer's job moves from writing → reviewing → specifying intent.
