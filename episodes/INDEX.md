| 004 | 2026-06-20 | [Holding Pattern](../episodes/004-verification-bottleneck/post.md) | The verification bottleneck, told as the honest upside story: once agents make code generation free, generation stops being the constraint and the bottleneck relocates to verification (proving the code is right).
